# Track-POD seguimiento GPS

APP Android/WebView para seguimiento de carga desde origen hasta destino.

Incluye:
- 5 vistas principales: Inicio / Fin, Tracking, Alertas, Usuario, Último envío.
- Clientes, orígenes y destinos cargados desde el Excel.
- Inicio de tránsito con GPS, fecha y hora.
- Cierre de tránsito con validación de GPS distinto al inicio.
- Alertas con GPS y fecha/hora.
- Tracking con distancia, ETA y puntos de control cada 300 km.
- Aviso especial para destinos Chile / Uspallata.
- Envío por WhatsApp al teléfono/grupo guardado.

Clientes: 4
Orígenes: 3
Destinos: 2
Versión: 1.1
