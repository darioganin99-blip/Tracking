# Track-POD seguimiento GPS

Aplicación Android/WebView para seguimiento de tránsito de cargas desde origen hasta destino.

## Funciones principales

- Inicio / Fin de tránsito
- Tracking GPS
- Registro de alertas
- Usuario: flota, chofer y teléfonos WhatsApp
- Último envío
- Datos de clientes, orígenes y destinos cargados desde Excel
- Envío de actualización y cierre por WhatsApp
- Validación de GPS al inicio y cierre
- Cálculo de distancia, ETA y puntos de control cada 300 km
- Aviso especial para destinos Chile / Uspallata

## Compilar APK

En GitHub:

1. Subir todos los archivos al repositorio.
2. Ir a **Actions**.
3. Ejecutar el flujo **Build APK**.
4. Descargar el APK desde **Artifacts**.
